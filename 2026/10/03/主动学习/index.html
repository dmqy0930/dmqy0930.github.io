主动学习

什么是主动学习？

The key idea behind active learning is that a machine learning algorithm can achieve greater accuracy with fewer training labels if it is allowed to choose the data from which it learns.

supervised learning的局限：高质量的标记数据较少——如何利用较少标注数据训练出表现较好的模型，利用主动学习选取的样本标注可以得到更好的模型表现

  • 一个工程化的问题：如何降本增效

  • 前提假设：存在对模型/特定任务更重要的数据

    • 与消融实验结果的差异？

  • 存在的几个问题

    • 为什么较少的标注数据反而能取得更好的效果？
    • 标注何种数据可以更高效地提升模型性能？为什么？
      • 能否训练一个（通用的？）主动学习的模型：学习需要标注的数据的分布——指导数据标记
      • 感觉可以用对比学习：正样本是能在平均水平以上提高模型性能的数据，负样本是提升效果低于平均水平的数据

主动学习的场景：对分类与回归场景的讨论

  • Pool-based scenario：此类场景通常提供一个未标记的数据池，主动学习策略在数据池中选取相应样本进行标记。
  • Stream-based scenario：此类场景中，数据以数据流的形式输入，主动学习策略需要确定对当前数据进行标记还是直接用现有模型预测。
  • Query synthesis scenario：此类场景较为少见，一个未标记的数据池通常也被提供，但是主动学习策略并不是在数据池中挑选样本进行查询，而是自行生成新样本进行查询。

主动学习策略

收集数据 -> 训练 -> 判断模型精度是否可以达到要求 -> 选择查询策略选择数据进行标记 -> 重新训练 -> ……

查询策略：效用度量

  • 查询策略分类：感觉类似于决策树
    • uncertainty sampling：把难以区分的样本数据提取出来
      • 置信度最低：$x_{LC} = argmax_x(1-P_\theta(\hat(y)|x)) = argmin_x P_\theta(\hat(y)|x)$
      • 边缘采样：样本被判别为两类的概率差距不大，$x_M = argmin_x(P_\theta(\hat(y_1)|x) - P_\theta(\hat(y_2)|x))$
      • 熵方法：不确定越大的数据越需要标注，$x_H = argmax_x(- \sum_i(P_\theta(y_i|x)\times ln P_\theta(y_i|x)))$
    • query-by-committee：类似集成学习，挑选多个模型都难以区分的样本数据
      • 投票熵：选择这些模型都无法区分的样本，$x_{VE} = argmax_x - \sum_i)(\frac{V_(y_i))}{C} \times ln\frac{V_(y_i))}{C}$
      • 平均KL散度：选择在多模型区分任务中KL散度较大的的样本，$x_{KL} = argmax_x \frac{1}{C} \ sum_{c=1}^C D(P_\theta ||P_c)$
    • expected model change(基于模型变化期望)：选择使梯度变化最大的样本数据
    • expected error reduction：选择通过增加一个样本就使Loss函数减少最多的样本数据进行标注
    • variance reduction：选择使方差减小最多的样本数据
    • density-weighted methods：在使用不确定性采样的时候，可以加入对样本稠密性的考虑（稠密的难区分数据标注价值大），$x_{ID} = argmax_x \Phi_A(x) \times (\frac{1}{U} \sum^U_{u=1} sim(x, x^{(u)}))6/\beta$
