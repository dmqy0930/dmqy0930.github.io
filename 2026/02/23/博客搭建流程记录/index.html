step4: 部署到github

  • 在github创建仓库：name.github.io
    • name必须与username一致才能显示网页
  • 插件安装
  • 连接到github
    • 法1: 使用个人访问令牌
      • 生成一个 token
        • 登录 GitHub，点击右上角头像 → Settings → 左侧边栏最下方 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。
        • 给 token 起个名字（如 hexo-deploy），勾选 repo 的所有权限（完整控制仓库）。
        • 拉到页面底部，点击 Generate token。
        • 复制生成的 token（注意：它只会显示一次，请保存好，如果丢失只能重新生成）。
    • 法2: 使用ssh
      • 生成ssh密钥：ssh-keygen -t ed25519 -C "mailbox@example.com"
      • 复制公钥：cat ~/.ssh/id_ed25519.pub
      • 粘贴到github
        • 登录 GitHub，点击右上角头像 → Settings。
        • 在左侧边栏选择 SSH and GPG keys。
        • 点击 New SSH key 或 Add SSH key。
        • Title 输入一个描述性名称（如 “My MacBook Air”）。
        • Key 粘贴之前复制的公钥内容。
        • 点击 Add SSH key，确认 GitHub 密码。
      • 测试：ssh -T git@github.com
        • 检查GitHub 的 SSH 主机密钥指纹
  • 修改配置文件
  • 部署

配置域名

  • 解析到境内服务器需要备案：推荐阅读
  • 解析到境外服务器（如github pages）就不用备案
    • 购买域名后，在购买平台进行解析
      • 添加主域名（如 example.com）的 A 记录：
        • 记录类型：选择 A
        • 主机记录：输入 @（代表主域名本身）
        • 线路类型：默认（或留空）
        • 记录值：输入 GitHub Pages 的 IP 地址。为了稳定，建议添加全部四个 IP，每条记录单独添加：185.199.108.153、185.199.109.153、185.199.110.153、185.199.111.153
        • TTL：保持默认（600秒即可）
        • 点击「保存」，重复添加其余三个 IP。
      • 添加 www 子域名的 CNAME 记录：
        • 再次点击「添加记录」
        • 记录类型：选择 CNAME
        • 主机记录：输入 www
        • 记录值：输入你的 GitHub Pages 地址，例如 用户名.github.io（注意最后有一个点，但通常系统会自动补全，不加点也可以）
        • TTL：默认
        • 点击「保存」
    • 在 GitHub 仓库中绑定自定义域名
      • 打开你的 GitHub 博客仓库（例如 用户名.github.io）。
      • 点击顶部菜单的 Settings。
      • 在左侧边栏找到 Pages（位于「Code and automation」下方）。
      • 在「Custom domain」输入框中输入你的域名（例如 example.com），然后点击 Save。
      • GitHub 会自动在仓库根目录创建一个名为 CNAME 的文件，内容就是你的域名。你也可以手动在本地 source 目录创建该文件并重新部署，效果相同。
      • 保存后，稍等片刻，GitHub 会显示“Your site is ready to be published…”，并可能自动为你启用 HTTPS（如果解析已生效）。
